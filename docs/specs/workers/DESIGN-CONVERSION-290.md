# conversion Worker 설계 — 단계분해 + Wilson CI/z-검정 (이슈 #290)

> 근거 논문: Sismeiro & Bucklin 2004 (task-completion 단계분해). Wilson CI·two-proportion
> z-검정은 표준 통계(Wilson 1927). 구현: `analysis/proportions.py` · 배선: `tools.get_funnel`.

## 1. 해결 문제

구 `drop_pct` 단순 임계(전환율 −20% 이상 하락 = 이상)는 표본 크기를 무시했다 —
view 10건짜리 저볼륨 기간에서 30%→10% 는 회원 2명 차이일 뿐인데 무조건 "하락
이상"으로 오탐했다. 신뢰구간과 유의성 검정으로 표본 크기가 판정을 가르게 한다.

## 2. 입력 데이터 (계약 매핑 — I-7, api-spec §4.4)

- 현재 기간 + **직전 인접 동일 길이 기간**(도구가 자동 산정·추가 조회 — 비교쌍).
- 직전 기간 조회 실패·날짜 해석 불가 → 비교만 생략(§3.4 관용, 본 요약 유지).
- 미집계 단계(`uncomputable_stages`)는 CI·검정 대상에서 제외("판단 제외" 유지, #184).

## 3. Feature 매핑 표 + 축약형 근거

| 논문 변수 | 계약 필드 | 판정 |
|---|---|---|
| 단계 조건부 전환확률 P(다음\|현재) | I-7 view/cart/checkout/purchase 비율 | ✅ 직접 |
| 세션 공변량(체류시간·재방문·페이지수) | 없음 | ❌ 제외 → **축약형** |
| 상품 이질성(어느 상품이 주도) | I-13 상품별 전환 수치 | 🔶 프록시(세션→상품 축) — LLM 이 get_behavior_events 로 보강 |

**축약 유효성**: 공변량 없는 로지스틱 회귀의 MLE 는 표본 비율과 동치다 — 따라서
Sismeiro 의 단계별 로지스틱은 현행 계약에서 "단계별 비율 추정 + 검정"으로 수학적
손실 없이 축약된다(공변량이 생기는 Phase B 에서 원형 복원).

## 4. 알고리즘

1. 단계별 Wilson CI(신뢰 95%) — Wald 대신 Wilson: 저볼륨·0%/100% 극단에서도
   구간이 [0,1] 안이고 폭이 붕괴하지 않는다.
2. 기간 비교 pooled two-proportion z-검정(양측) → p<α 면 방향 판정, 아니면
   "유의한 변화 없음". pooled 0/1(분산 0)은 p=1.0 처리.
3. 단계별 독립 판정 — 한 단계 미집계여도 나머지 단계는 검정한다.

## 5. 판단 기준

`seller_wilson_confidence=0.95` · `seller_rate_test_alpha=0.05` (config, 기동 검증).

## 6. 출력 → LLM

`view→cart 10.0% [95% CI 5.6%~17.4%, n=100](직전 12.0%, p=0.541 — 유의한 변화 없음)`.
LLM 규칙(프롬프트): p≥α 는 "유의하지 않음"으로 보고 — 병목 서사 금지, n 병기로
저볼륨 과신 방지, "검정 제외/비교 생략"은 판정 보류.

## 7. degrade·테스트

- 재현 테스트(`test_seller_analysis_proportions.py`): 동일 모비율 → 비유의 / 실차이
  → 유의 / **동일 낙폭이라도 n=10 비유의·n=1000 유의**(교체 목적 그 자체) /
  Wilson 교과서 검증값(3/10 → [0.108, 0.603]) / 결정론.
- 도구 테스트: 직전 기간 자동 조회 인자 검증·직전 실패 관용·미집계 제외.
