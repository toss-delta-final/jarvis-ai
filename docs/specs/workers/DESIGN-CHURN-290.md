# churn Worker 설계 — Wilson CI + 신호 순위화 (이슈 #290)

> 근거 논문: Ahn et al. 2020 (도메인별 이탈 정의·피처 카탈로그 서베이). 구현:
> `analysis/proportions.py`(공용) · 배선: `tools.get_churn_cohort`.

## 1. 해결 문제

현행은 이탈률·신호 수치를 나열만 했다 — 유의성 판정(이 변화가 우연 범위인가)과
주도 신호 판정(어느 신호가 커졌나)이 없어 LLM 이 감으로 서사를 만들었다.

## 2. 입력 데이터 (계약 매핑 — I-16, api-spec §4.4 v0.19.1)

- 현재 + **직전 인접 동일 길이 기간** 2회 조회(inactiveDays 동일 적용).
- 코호트 0명은 직전 조회 전에 조기 반환(비교 대상 없음 — 보조 조회 비용 절약).
- 직전 코호트 0명·churnRate 결측·조회 실패 → 비교 불가 표기(현재 판정은 유지).
- 보조: I-14(취소·반품 전이), I-8(기본 비활성 — Error 관용).

## 3. Feature 매핑 표 + 이탈 정의

| 논문 변수 | 계약 필드 | 판정 |
|---|---|---|
| 이탈 정의(activity-based) | inactive_days 무활동(현행 유지) | ✅ — Ahn 서베이의 비계약(non-contractual) 도메인 표준 정의로 근거화 |
| 취소·반품·가격노출·검색무결과 신호 | I-16 `preChurnSignals` | ✅ 직접(검색무결과는 상시 0 — 도구 노트) |
| 구매간격 규칙성·카테고리 다양성 | 없음 | ❌ Phase B(고객별 구매 이력 계약 필요) |
| 신호 정규화 분모 | `cohortSize` | ✅ (`count/cohort_size` 비중) |

## 4. 알고리즘

1. 이탈률 Wilson CI — I-16 은 fraction 만 주므로 `churned = round(rate×cohort)` 로
   표본 복원(결정론 근사, 문서화).
2. 기간 비교 two-proportion z-검정 → "유의한 하락/상승/변화 없음".
3. 신호 순위화: {취소, 반품(사유 합), 가격인상 노출, 검색 무결과} 를 코호트 대비
   비중으로 정규화 → 직전 기간 비중과의 변화(%p) 병기 → 상위
   `seller_churn_signal_top_k`(3) 를 원인 후보로. 원 count 는 보존(judge 검증 규약).
4. #197 규칙 전부 계승: 코호트 0명≠이탈률 0% / churnRate 결측 = 판정 보류 /
   fraction 표기(:.1%) / members 상한.

## 5. 판단 기준

`seller_rate_test_alpha=0.05` · `seller_wilson_confidence=0.95` · `seller_churn_signal_top_k=3`.

## 6. 출력 → LLM

`코호트 20명 중 이탈률 60.0% [95% CI 38.7%~78.1%], 직전 기간(…) 55.0% 대비 p=0.749
— 유의한 변화 없음. 이탈 전 신호(원인 후보 상위 3, 코호트 대비 정규화): 1) 취소
12건·코호트 60.0%(직전 55.0%, +5.0%p) …`. LLM 규칙(프롬프트): **상관≠인과 명시
강제** — "취소 때문에 이탈"이 아니라 "취소와 동반됨·원인 후보"로만 서술, p≥α 는
이탈 증가 서사 금지.

## 7. degrade·테스트

- 도구 테스트: 2회 조회 인자(동일 inactiveDays)·신호 순위 표기·직전 코호트 0명
  비교 불가·결측 보류(이탈률 0.0% 위장 금지 단언은 신호 비중 0.0% 와 구분).
